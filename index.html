🔎 ตัวอย่าง

Adaptive Escape Hunter
Create a practical enemy AI system that learns the player's preferred escape routes. Define: - Detection system - Memory system - Behavior states - Decision logic - Player counterplay - Pseudocode - Balance parameters - Example encounter
Sound Tracking Predator
Design an enemy that hunts using sound. Define different noise sources, detection radius, investigation behavior, false sounds, player counterplay, and anti-frustration safeguards.
